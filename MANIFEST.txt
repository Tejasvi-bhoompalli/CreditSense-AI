HOW TO RUN (Windows 10/11)
--------------------------
1. Extract this archive.
2. Open the extracted folder in VS Code or Google Antigravity.
3. python -m venv .venv
   .venv\Scripts\activate        (PowerShell: .venv\Scripts\Activate.ps1)
4. pip install -r requirements.txt
5. streamlit run app.py
6. Open http://localhost:8501 in your browser.
7. python -m pytest -q           (test suite)

The trained model (artifacts/model/model_bundle.joblib) and the dataset
(data/UCI_Credit_Card.csv) are included, so retraining is not required.
Retrain only if you want to: python -m src.train_model
